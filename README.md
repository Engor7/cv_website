## 📖 About This Project

This is a personal portfolio website built to showcase my skills in modern web development. The project demonstrates:

- 🎨 **UI Library** – Custom-built reusable components
- 🔄 **API Integration** – Real-time data from third-party services (Binance, Weather API)
- ✨ **Smooth Animations** – Enhanced user experience with fluid transitions
- 🎵 **Music Player** – Custom audio player implementation
- 🌍 **Internationalization** – Multi-language support (EN/RU)
- 🌓 **Theme Toggle** – Light and dark mode support

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- Yarn or npm

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/cv_website.git
   cd cv_website
   ```

2. **Install dependencies**
   ```bash
   yarn install
   # or
   npm install
   ```

3. **Run development server**
   ```bash
   yarn dev
   # or
   npm run dev
   ```

4. **Build for production**
   ```bash
   yarn build
   # or
   npm run build
   ```
